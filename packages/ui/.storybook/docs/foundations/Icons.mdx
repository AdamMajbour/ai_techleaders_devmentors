# Icons

The icon library is **lucide** (`lucide-react`), as configured in `components.json`. Icons are drawn as lines in the current text colour. Emoji are never used as icons (A01, proposal P3).

## Sizes

| Size | Use it for |
|---|---|
| 16 px (`size-4`) | Inside a button or next to body text |
| 20 px (`size-5`) | Standalone or beside a section title |

Both sizes are the author's proposal, listed for decision in `POSTEP.md`.

## When an icon needs a label

1. **An icon next to text is decoration.** Hide it from screen readers with `aria-hidden="true"`.
2. **An icon alone is a control, so it needs a name.** Give the button `aria-label` ("Close"), and a visible text where space allows (WCAG 1.1.1, 4.1.2).
3. **An icon never carries a status alone.** "Accepted" is a word with an icon, not an icon (WCAG 1.4.1).
4. **No icon on a coloured tile next to every heading.** It is a mark of generic design (A01).
