# Checkbox

## 1. What it is for

A checkbox records a yes or no choice that the user confirms when they submit a form, such as agreeing to terms.

<Canvas of={CheckboxStories.WithVisibleLabel} />

## 2. When to use it

- Agreeing that a note feeds AI answers before publishing it (E02-S01).
- Accepting the pilot terms before paying (E03-S01).
- A mentor choosing to be listed.

## 3. When not to use it, and what to use instead

| Situation | Use instead | Why |
|---|---|---|
| An action that happens at once | `Button` | A checkbox is state, not an action |
| One choice among several | `Select` | Only one value is allowed |
| Going to another page | `TextLink` | Navigation, not state |

Consent is never pre-checked. The user must tick it themselves.

## 4. Anatomy

1. **Box**, 24 px square, with a `--input` outline.
2. **Check mark** when checked.
3. **Label** (required, visible), next to the box. Clicking the label toggles the box.

## 5. Variants

One variant, one size.

## 6. States

<Canvas of={CheckboxStories.States} />

| State | What the user sees | Source |
|---|---|---|
| Unchecked | Empty box with a `--input` outline | WCAG 1.4.11 |
| Checked | Filled with `--primary` **and** a check mark: state is not shown by colour alone | WCAG 1.4.1 |
| Hover | No separate style | Proposal |
| Focus | A solid 2 px ring in `--ring`, 2 px gap | WCAG 2.4.7 |
| Disabled | `--muted` fill and muted mark. Explain why in the label's hint | Decision 2026-10-27 |
| Invalid | `--destructive` outline plus an error text and icon from `Field` ("Tick the box to continue") | WCAG 1.4.1, 3.3.1 |
| Loading, pressed | Not applicable | |

## 7. Behavior and accessibility

- **Keyboard:** `Tab` focuses it, `Space` toggles it (WAI-ARIA APG checkbox pattern).
- **Role:** `checkbox` with `aria-checked`. A screen reader announces "checked" or "not checked".
- **Label:** a visible `<label>` around the box and text, or `aria-label` for a rare box without text.
- **Target size:** 24 × 24 px (WCAG 2.5.8), and the label is part of the clickable area.

<Canvas of={CheckboxStories.ToggleByClickAndSpace} />

## 8. Content

- **Label:** a full sentence in the first person that says what the user agrees to: "I understand that the AI writes the answer."
- **Length:** up to two or three lines. Longer terms belong behind a `TextLink`.
- **Positive wording:** "I accept", not "I do not decline".

<Canvas of={CheckboxStories.LongLabelNarrow} />

## 9. Responsiveness

The box keeps its size and the label wraps. At 320 px the label takes the remaining width beside the box.

## 11. Code

```tsx
import { Checkbox } from '@devmentor/ui';

<label>
  <Checkbox checked={agreed} onCheckedChange={(value) => setAgreed(value === true)} />
  I accept the pilot terms
</label>
```

```tsx
// Typical: consent before publishing a note. The button stays blocked until it is ticked.
<Button disabledReason={agreed ? undefined : 'Tick the box to publish'} onClick={publish}>
  Publish note
</Button>
```

## 13. Related

- **Confused with:** `Button` (an action) and `Select` (one of several).
- **Used in patterns:** Form (consent), Publish notice panel (E02), Terms acceptance (E03).
