# E02 Notes and vault

A mentor publishes notes and is told they feed AI answers. A seeker buys a vault answer built from mentors' notes. The mentors whose notes are cited read the answer first, and are credited when it is released (backlog: E02, issue #8). Each state below is one story in **Product > Screens > E02 Notes and vault**.

Sources: the vault spec (`.ai/specs/2026-10-27-pilot-vault-answers.md`), the backlog and the product brief (D09, D10, D14, R03, N02). The screens are examples built from the design system, with example data and no routing.

## Steps of the flow

1. A mentor writes a note and saves it as a draft (E02-S01).
2. They read the notice, agree and publish it. They agree again every time they publish.
3. A seeker asks the vault a question and pays 10 EUR (E02-S03).
4. An AI writes an answer from the published notes of all mentors except the seeker's own.
5. Every mentor whose note is cited reads the answer and approves or rejects it (E02-S02). One rejection rejects the answer and refunds the seeker.
6. When every cited mentor has approved, the answer is released with its sources and the mentors are credited.

## Rules this epic relies on

| Rule | Where it shows | Source |
|---|---|---|
| The mentor reads the notice and agrees again every time they publish | One note | D09 |
| A note can be taken down at any time | One note | R03 |
| Every cited mentor reads the answer first, until 14 December 2026 | Answers to review | D09, D18 |
| One rejection rejects the whole answer | Answers to review | Vault spec, Q4 |
| The answer is labelled as AI-generated and lists "Mentor name, note title" | The vault answer | D10, D14 |
| No ratings, no link to the note | The vault answer | N02, vault spec |
| The price comes before the question | Ask the vault | R04 |
| Nothing is charged when the vault cannot run | Ask the vault | Vault spec (a refusal before any payment) |
| Credits are not a payout | Notes and credits | Vault spec, credits panel |

## Work still to do in the product

- **Routes of the vault spec:** `/api/notes` and its actions (`publish`, `take-down`), `/api/vault-answers` (create, list, read, `reconcile-payment`, `approve`, `reject`), `GET /api/vault/previews`, `GET /api/mentor/credits`, and the operator routes.
- **Pages:** `(mentor)/mentor/notes`, `/mentor/notes/[id]`, `(mentor)/mentor/previews`, `(student)/vault`, `/vault/[id]`.
- **Wiring:** polling of a vault answer until it ends, the notice text and its version from the server (reviewed in E03-T02), the preview window from the server.

- **Payment return of a vault answer** reuses the payment return of E01 (Patterns: Paid action flow).
- **A confirmation before Reject** is not built (see `ReviewItem`). Whether one is needed is a question for the owner.
- **Payout of credits** has no spec (E03-S02 is not built).
- **A monospace font in the note editor** is a proposal (R01.2).
